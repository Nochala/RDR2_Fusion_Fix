# RedDeadRedemption2 Fusion Fix
A big project of mine that's deeply inspired by GTA IV Fusion Fix by ThirteenAG.
This eventually aims to be a huge collection of various gameplay fixes and improvements for RDR2.



### Current features in development

### [ Startup ]
- SkipIntroSplashes
- SkipLegal
- StraightToStoryMode
  
### [Engine]
- YTDCrashFix=true
- ExtendStreamingPools=true
- FixHighFPSPhysics=false
- FixHighFPSStamina=false
- FixHighFPSFishing=false
- FixHighFPSDeadEye=false
- FixStreamingStutter=false
- FixTexturePopIn=false
- FixFramePacing=false
- FixVRAMLeak=false
